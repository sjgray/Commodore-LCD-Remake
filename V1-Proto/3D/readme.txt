CLCD Re-Make Project by Steve Gray and Mike Naberezny
==================== CBMSTEVE.CA

This folder contains 3D generated STL files that can be printed.
The CASE folder is for the main CLCD case. This must be assembled
from all the different STL files. The Top comes in two pieces and
must be glued or attached with screws. The bottom has areas for
installing brass inserts for mounting the pcb. The TOP has areas
for mounting the LCD controller, backlight board, and RGB2HDMI adapter.
The Display is designed for a 10.25" 60-pin "bar" type LCD panel
(see webpage for details).

The KEYCAPS folder is for replica CLCD keycaps that can be printed
with a resin printer and mounted on standard MX switches.
