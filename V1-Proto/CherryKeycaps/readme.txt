CLCD Re-Make Project by Steve Gray and Mike Naberezny
==================== CBMSTEVE.CA

This folder contains SVG files that can be sent to MAXKEYBOARD.COM
to get "Custom Color" Keycaps printed. This contains all the CLCD
keycaps for the Inverted-T MX keyboard and uses MAXKEYBOARD's
104 ANSI set with 6.0U spacebar.

There are two files:
1) Top printing
2) Side (front) printing
