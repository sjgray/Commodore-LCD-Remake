CLCD Re-Make Project by Steve Gray and Mike Naberezny
==================== CBMSTEVE.CA

This folder contains:

CLCD      - Kicad design files for CLCD Proto V1 which does not work without fixes
KEYBOARD  - Kicad design files for CLCD Keyboard with Inverted-T cursor. Requires one fix
PLA-BOARD - Kicad design files for EPROM PLA Board - no longer required
_FIXES    - Pictures of fixes required to make the V1 Prototype CLCD board functional
