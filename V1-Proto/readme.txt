CLCD Re-Make Project by Steve Gray and Mike Naberezny
==================== CBMSTEVE.CA

This folder contains the V1 prototype files.

The folders are:

3D             - STL files for 3D printed case and keycaps
CPLD           - Source for CPLD decode
Firmware       - Original and new firmware source and build scripts
CherryKeycaps  - SVG files to create custom cherry keycaps from MaxKeyboard.com
PCB            - Kicad design files for CLCD motherboard, EPROM-PLA, and MX Keyboard
